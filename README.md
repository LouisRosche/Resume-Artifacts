## 🚀 Getting Started

### Prerequisites

```bash
# Python 3.8 or higher
python --version

# pip package manager
pip --version

# Git
git --version
```

### Installation

1. Clone the repository:
```bash
git clone https://github.com/LouisRosche/Resume-Artifacts.git
cd Resume-Artifacts
```

2. Install Python dependencies:
```bash
pip install -r requirements.txt
```

3. Navigate to specific artifact:
```bash
cd mtss-dashboard
python mtss_dashboard.py
```

### Individual Artifact Setup

Each artifact directory contains its own README with specific setup instructions.

## 📊 Usage Examples

### MTSS Dashboard
```python
from mtss_dashboard import MTSSDashboard

dashboard = MTSSDashboard()
dashboard.load_sample_data()
dashboard.create_tier_distribution_chart().show()
```

### Student Risk Predictor
```python
from student_risk_predictor import StudentRiskPredictor

predictor = StudentRiskPredictor()
predictor.train_model()

risk_score = predictor.predict_risk_score(student_data)
print(f"Risk Score: {risk_score:.2f}")
```

### Progress Monitoring
```python
from progress_monitoring_system import ProgressMonitoringSystem

system = ProgressMonitoringSystem()
weekly_report = system.generate_weekly_intervention_report()
system.export_weekly_reports()
```
